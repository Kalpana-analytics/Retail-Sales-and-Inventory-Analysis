# Retail Sales and Inventory Analysis

## Project Overview
This project focuses on analyzing retail sales and inventory data to identify sales trends, stock availability, and business insights.

## Objectives
- Analyze product sales
- Monitor inventory levels
- Identify low stock products
- Track monthly sales performance
- Generate business insights

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Dataset Columns
- Product ID
- Month
- Unit Sale
- Product Name
- Supply Time
- Quantity On Hand

## Key Analysis
- Monthly sales analysis
- Product-wise sales
- Inventory monitoring
- Low stock identification

## Skills Gained
- Data Cleaning
- Data Analysis
- Inventory Analysis
- Sales Analysis
- Pandas Operations
